# 🎟️ سامانه شبیه‌سازی رزرو صندلی با Flask و Multi-threading

این پروژه یک سامانه‌ی شبیه‌سازی رزرو صندلی است که با استفاده از **چندریسمانی (Multi-threading)** و **فریم‌ورک Flask** در زبان پایتون توسعه داده شده است.  
در این سیستم، کاربران (نخ‌ها یا threadها) با اولویت‌های متفاوت و رفتارهای تصادفی تلاش می‌کنند صندلی‌هایی را رزرو کنند. پروژه به طور کامل مفاهیم سیستم‌عاملی مانند **هم‌زمان‌سازی (Synchronization)**، **مدیریت شرایط رقابتی (Race Condition)** و **اولویت‌بندی** را شبیه‌سازی می‌کند.

---

## ✨ امکانات کلیدی

- ✅ شبیه‌سازی درخواست‌های هم‌زمان با استفاده از `threading.Thread`
- 🔐 جلوگیری از Race Condition با قفل‌های `threading.Lock`
- 🔢 تعریف محدودیت تعداد صندلی و نخ‌های هم‌زمان
- ⚖️ سیستم اولویت‌بندی و زمان‌بندی درخواست‌ها با `PriorityQueue`
- 🔁 تلاش مجدد برای رزرو ناموفق
- 📈 رابط کاربری وب با Flask شامل:
  - نمودار میله‌ای و دایره‌ای از وضعیت رزروها
  - نقشه گرافیکی صندلی‌ها (نمایش رزروشده و آزاد)
  - جدول لاگ‌گیری دقیق با جزئیات
- 📄 ثبت لاگ کامل در فایل `log.txt` با Timestamp
- 🧪 تست‌های خودکار با استفاده از `pytest`
- 🛠 ساختار ماژولار و قابل گسترش

## 🚀 نحوه اجرا

### ۱. دریافت پروژه
```bash
git clone https://github.com/YOUR_USERNAME/seat-reservation-system.git
cd seat-reservation-system
```

### ۲. نصب پیش‌نیازها
```bash
python -m venv venv
source venv/bin/activate  # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### ۳. اجرای رابط وب (UI)
```bash
python run.py
```

سپس مرورگر را باز کرده و وارد آدرس زیر شوید:
[http://localhost:5000](http://localhost:5000)

---

### 🖥 اجرای حالت خط فرمان (CLI)
```bash
python run.py cli
```

در این حالت، فایل‌های زیر ایجاد خواهند شد:
- `log.txt`: شامل لاگ دقیق همه نخ‌ها
- `seat_state.json`: وضعیت نهایی صندلی‌ها

## ❓ اگر هم‌زمان‌سازی وجود نداشت؟

در صورت عدم استفاده از قفل‌ها (Locks):
- چند نخ ممکن بود یک صندلی را هم‌زمان رزرو کنند
- اطلاعات صندلی‌ها متناقض و خراب می‌شد
- فایل لاگ در معرض اختلال و بهم‌ریختگی قرار می‌گرفت

به همین دلیل، از `threading.Lock` برای محافظت از منابع مشترک استفاده شده است.
