🎟️ سیستم شبیه‌ساز رزرو صندلی با Flask

یک پروژه‌ی کوچک ولی کاربردی برای شبیه‌سازی سیستم رزرو صندلی با استفاده از Python و فریم‌ورک Flask، همراه با پشتیبانی از پردازش هم‌زمان (multi-threading).

در این سامانه، چندین کاربر به‌صورت هم‌زمان (شبیه‌سازی‌شده توسط ریسمان‌ها) با اولویت‌های مختلف تلاش می‌کنند صندلی رزرو کنند. اولویت، زمان ورود، تلاش مجدد در صورت شکست، احتمال لغو تصادفی، و داشبوردی گرافیکی برای نمایش وضعیت، همگی در طراحی این پروژه لحاظ شده‌اند.
این پروژه مناسب چه کسانی‌ست؟

    علاقه‌مندان به مباحث برنامه‌نویسی هم‌زمان در پایتون

    توسعه‌دهندگانی که به دنبال یادگیری ساخت اپ‌های ساده تحت وب با Flask هستند

    کسانی که به طراحی معماری ماژولار و قابل توسعه علاقه دارند

✨ قابلیت‌ها

    پشتیبانی از چندریسمانی برای شبیه‌سازی رفتار کاربران به‌صورت هم‌زمان

    کنترل تعداد صندلی‌ها و محدود کردن تعداد درخواست‌های هم‌زمان

    تصمیم‌گیری بر اساس اولویت و زمان درخواست

    تلاش مجدد خودکار برای درخواست‌های ناموفق

    داشبورد گرافیکی تعاملی شامل:

        نمودارهای آماری وضعیت رزروها

        نقشه‌ی گرافیکی صندلی‌ها

        جدول لاگ عملیات با جزئیات

    الگوریتم زمان‌بندی ترکیبی (HybridScheduler)

    تست‌های خودکار با pytest

    طراحی ماژولار و قابل گسترش

🚀 راه‌اندازی و اجرا
پیش‌نیاز:

    Python 3.10 یا بالاتر (تست‌شده روی Python 3.13)

مراحل نصب:

git clone https://github.com/salimi-404/seat-reservation-system.git
cd seat-reservation-system

python -m venv venv
source venv/bin/activate      # یا در ویندوز: venv\Scripts\activate

pip install -r requirements.txt

اجرای برنامه:
حالت وب (داشبورد گرافیکی)

python run.py

در مرورگر باز کنید: http://localhost:5000
حالت CLI (بدون رابط گرافیکی)

python run.py cli

در پایان، دو فایل خروجی دریافت خواهید کرد:

    log.txt: گزارش کامل عملیات

    seat_state.json: وضعیت نهایی صندلی‌ها

🧪 اجرای تست‌ها

pip install pytest
pytest

اگر همه چیز درست پیش برود، خروجی شبیه زیر خواهد بود:
